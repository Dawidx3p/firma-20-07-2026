# UL CAR — koncepcja KAIROX

Niezależne demo, niezlecone i niezatwierdzone przez UL CAR. Kopia projektu ul-car-hero dostosowana do Kairox.

Popup i stały podpis opisują charakter koncepcji. Kontakt jest nieaktywny. Meta robots: noindex, nofollow, noimageindex. Brak formularzy.

Docelowy adres demo: https://kairox.pl/ul-car/. Źródłowy projekt pozostawiono bez zmian.
